# Nostra Fashion Website

Nostra is a modern and responsive fashion shopping website created using HTML and Tailwind CSS. This project is designed for beginners to learn frontend web development and responsive UI design.

## Features

- Responsive Navbar
- Hero Section
- Product Cards
- Fashion Collection Design
- Contact Form
- Mobile Friendly Layout
- Tailwind CSS Styling
- Simple and Clean UI

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (Optional)

## Pages Included

- Home Page
- Products Section
- Contact Section

## Project Purpose

This project was developed for practice and learning frontend web development concepts such as:

- Responsive Design
- Flexbox and Grid
- Tailwind CSS Utility Classes
- Website Layout Creation
- Modern UI Design

## How to Run the Project

1. Download or Clone the Repository
2. Open the project folder
3. Open `index.html` in your browser
